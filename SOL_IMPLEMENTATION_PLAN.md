# Whole-project implementation mandate

Reconstruct the complete PC game from source, using the Android reconstruction
where verified PC identity, ABI, fields and behavior support it. The goal remains
active across checkpoints; comparison percentages and a linked executable do not
establish completion or a playable game.

Use the [current roadmap](docs/roadmap.md),
[work plan](config/progress-plan.md) and
[execution policy](config/transfer-execution.md) for ongoing work. The complete
2026-10-03 handoff is preserved in
[the development archive](docs/development/implementation-plan.md); its dated
runtime observations and starting counts are historical.

Continue coherent source families and real Windows/resource providers, preserve
human edits and existing exact results, and keep missing actions explicit. No
fabricated provider, forced publication, guard bypass, comparison mask or cropped
native extent may substitute for reconstruction. Integrate reviewed subsets
without waiting for a complete whole-program map or every unrelated type.

The existing authorization for continued work, coherent half-hour checkpoints,
direct-main pushes and verification of each exact pushed revision remains in
[the execution policy](config/transfer-execution.md). Keep heartbeats quiet when
there is no meaningful change. A checkpoint does not end the whole-project goal.
